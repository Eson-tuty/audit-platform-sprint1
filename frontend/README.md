# React frontend starter

Create the Vite React TypeScript app, install dependencies from the root README, then copy this `src` directory into the Vite app.

Add `VITE_APP_URL=https://app.example.com` to `.env` when the audit application is deployed separately.

This initial UI is only the public website shell. Sprint 1 also needs a separate audit-app entry point/layout, login, MFA challenge, tenant switcher and protected route handling.
